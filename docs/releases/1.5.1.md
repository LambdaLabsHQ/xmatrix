# xMatrix 1.5.1

Changes since 1.5.0. This release updates xmatrix.sh to match the credit-pack
policy already running on the Hub.

## Credit packs

- A new one-time credit pack costs **$10 for 5,000 credits**, plus applicable
  tax. Previously, $10 bought 10,000 credits. The purchase button, pricing
  reference and draft Terms now reflect the new quantity.
- The purchase button reads the pack quantity from the server. Payment
  confirmation no longer promises a fixed quantity that could differ from the
  purchase being confirmed.

## Compatibility and upgrade

- A checkout started before the policy change keeps the quantity recorded when
  it was created, including an earlier 10,000-credit pack. Completing that
  payment later does not reduce it to 5,000. Existing purchased balances are
  unchanged.
- Pro still includes 5,000 credits per seat each month. Pack credits carry over
  while the Space exists and are used after the included allowance. The pack
  price and monthly seat prices are unchanged.
- Reload xmatrix.sh to get the corrected purchase and confirmation text. No CLI
  or native app update is required; this release republishes only the Web.

## Known limitations

- A tab left open on an older Web build can still show the previous pack size
  until it is reloaded. Newly created checkouts use the server's current policy.
- This correction does not automatically open its release notes. The
  version-specific release page remains available.
