# xMatrix 2.3.0

Conversations are easier to follow: a pill takes you back to what a person last
said, code reads in colour, and app results read as their answer. On a phone,
moving between a conversation and its list feels physical. Agents can now see
which computers run which Agents before they summon one.

## Back to what a person said

When many Agent replies push the last message from a person out of view, a small
pill with that person's face and name floats at the top of the conversation.
Click it to jump back to their message. It disappears once a person's message is
on screen, and it finds the message even when it has not been loaded yet.

## Code that reads like code

A code block in a conversation is now one piece of tinted paper, the same as a
code block on a Page, instead of a bordered box with a CODE title or a chip per
line. Long lines scroll sideways, copy sits in the corner, and the language shows
as a quiet label only when the block names one. Code in conversations and on
Pages takes syntax colours in soft inks, chosen by the block's language, or by
its content when a grammar clearly fits; a table or a log stays plain. Quotes in
a message use the same tinted paper.

## App results that read as their answer

- A result that ends in a table or code block no longer shows stray fence marks
  and a run-on link. The answer is drawn as formatted text, and the link becomes
  an **Open in …** action.
- A private result shown to you is formatted the same way, without loading
  images or media from the hosts it names. A small lock beside its status says
  who can see it.
- A Gmail message an Agent read appears as an email card: sender, time, subject,
  whether the sender was verified, the body (folded when long) and its links.
  Mail content stays plain text.
- An App's **Recent activity** is now a call log: one line per call with its
  time, action, who made it and how it ended. Calls an Agent made name that
  Agent, for example "claude for Daniel". Results stay in the conversation.
- An action approved shortly before its sign-in expired now explains that the
  connection or approval needs review, instead of reporting a provider failure.
- A command whose JSON contains a web address runs again instead of being read
  as ordinary text.

## Moving between a conversation and its list on a phone

On a phone, opening a conversation and going back no longer slides the whole
page. The top bar, its sign and the controls at the bottom stay in place; only
the conversation and its channel list move, side by side, and the names slide
through the sign. The motion is smoother and lighter on the phone's processor.

## Find the right computer and Agent

`xmatrix agent list` now works inside an Agent's session without naming a Space.
It groups Agents by computer and shows whether each computer is online, how much
provider quota is left, and why an enabled Agent cannot take work. Use
`--machine` to see one computer. When a summon names a computer that does not
run that Agent, the reply now lists the Agents that computer does run.

## More apps and Agents

- The Cloudflare app can list zones, DNS records, registered domains and
  Workers, check a domain's price, create zones and DNS records, register a
  domain and attach a hostname to a Worker. Registration checks availability
  first, refuses premium names and turns on auto-renew; adding a DNS record never
  overwrites a different existing value.
- OpenCode is installed and managed as its 2.x line. An existing 1.x install is
  upgraded across to 2.x, and signing in no longer fails with "Database is not
  empty and has no session table".

## Fixes

- Returning from Stripe Checkout or the billing portal opens Billing again, where
  your payment is confirmed.
- The Mac app opens with its window buttons already centred on the side rail,
  instead of jumping after the first frame.
- Returning to the app on a slow connection no longer says "Reconnecting" unless
  reconnecting actually failed. Offline still shows right away.
- While the service cannot be reached, failed reconnect attempts no longer
  re-read every list in the workspace.

## Compatibility and actions

This release updates the stable Web, the CLI/daemon and Desktop. Update the
CLI/daemon or Desktop, then restart or reborn running Agent instances to use the
new `agent list`, launch guidance and OpenCode handling. No data migration is
needed.

If your workspace connected Cloudflare before this release, reconnect it in
Apps so it grants the new permissions the zone, DNS, domain and Worker commands
need.

## Known limitations

- The iOS app is not part of this release. Version 2.2.0 is still waiting for
  its first App Store review.
- In the iOS app, the edge swipe back follows the new phone motion only with a
  newer iOS build; earlier builds keep the previous sliding snapshot.
- Recent activity names the calling Agent only for calls recorded since the
  service started keeping it; older calls show only their person.
