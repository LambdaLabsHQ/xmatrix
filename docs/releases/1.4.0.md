# xMatrix 1.4.0

Changes since 1.3.0. This stable release updates the site at xmatrix.sh and the
CLI, including the machine daemon. Desktop, Android and iOS are not republished.

## New

- The image viewer zooms, pans and moves between images. Pinch, scroll,
  double-tap, click or the zoom controls; drag a zoomed image to pan; swipe or
  use the arrow keys to move through the gallery. Drag down to close. An image
  written into a message opens in the same viewer. An image that is itself a
  link stays a link.
- A command's result sits on the command. Switching model or effort, stopping
  an Agent, and a refused reborn or handoff show their outcome there instead of
  as a separate system message. When a summon cannot start, or a stop you asked
  for finishes or fails, that result is on the command too.
- A Free Space's 500 lifetime writes now include page edits as well as Channel
  messages.

## Improvements and fixes

- A Page opens as it is now. Changes since you last read it are a card in the
  margin; opening that card marks them in place. Selecting a passage to comment
  works when the drag starts in code or bold text, or ends past the line. The
  comment is on its card as soon as you send it, and clicking away closes the
  box. The margin stays within the page: an open thread scrolls beside its
  passage instead of lengthening the page.
- Agents on a comment card show that vendor's face and whether they are working.
- Closing the image viewer no longer activates whatever was under the tap.
- A steer that Codex accepts as its turn ends is delivered once. It is not sent
  again as the next turn.
- A Machine that is still connected no longer stays offline after a missed wake.
  The updated daemon also asks the Hub itself after a minute with no Hub traffic.
- Summon, stop and handoff status on a command updates when it changes, instead
  of waiting on a poll.
- Instructions the Hub sends to one Agent Instance (a switch continuation for an
  older runtime, a capacity retry, or page co-writing) stay in that Instance's
  inbox. They no longer appear in the Channel timeline, its preview or its
  unread count.

## Compatibility and upgrade

- Reload xmatrix.sh for the Web. Run `xmatrix update` for the CLI and machine
  daemon. Already-running Agent processes keep their current launch behavior
  until restarted or reborn. An older daemon still runs; the check after a
  minute of silence needs this daemon.
- On a Free Space, each committed page revision counts toward the 500 writes.
  After that, further page commits are refused the same way messages are, and
  the text you were writing stays pending with the reason. Reading is unchanged.
  On Pro, an Agent's page revision spends credit as a message does. A past-due
  Space in its read-only grace also refuses page revisions.
- This CLI accepts a model or effort switch continuation on its own frame. An
  older CLI still receives that continuation as an Instance instruction, which
  people do not see in the Channel.
- Desktop and Android stay on 1.2.0. iOS stays on 1.0.250 while it waits for
  App Review. Beta builds of those apps open beta.xmatrix.sh. Stable apps and
  xmatrix.sh stay on this release's Web. Links from the Hub still open
  xmatrix.sh.

## Known limitations

- A result for a Run the Channel did not ask for (an Automation, a stop from
  elsewhere, or startup cleanup) is still posted as its own notice.
- A notice whose command is not loaded still appears as its own row.
- This release does not replace Desktop, Android, or the iOS version currently
  awaiting App Review.
