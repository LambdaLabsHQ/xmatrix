# xMatrix 4.10.0

This release updates the website (`4.10.0`, up from `4.9.0`) and the CLI and daemon (`4.10.0`, up from `4.9.2`). Desktop (`4.9.1`), Android (`4.6.2`), and iOS (`4.0.4`, waiting for Apple App Review) keep their current versions. Hub and automation improvements listed below are already live.

## Website

- **Parameterized Agent handoffs.** Handoffs now support choosing a successor harness, model, machine, and effort directly in the composer (`@source:1:handoff:@target` with completion for successor options). Clicking **Handoff** in the Agent dock fills the composer with the handoff command instead of opening a separate picker, and a source Agent can be handed off again after a failed handoff.
- **Actionable refusal and startup failure messages.** Refused handoffs, reborns, launch rejections, and machine startup failures now render a clear explanation and concrete next steps in your saved language (English or Chinese), moving raw failure codes and Hub details into an expandable **Details** section.
- **Six-language public website and comparison pages.** The homepage, download page, support page, user guide (`/docs`), and 19 competitor comparison pages (`/<competitor>-alternatives`, with live product previews and cited sources) are now localized across English, Simplified Chinese (`/zh`), Traditional Chinese (`/zh-tw`), Japanese (`/ja`), Korean (`/ko`), and Spanish (`/es`), with a footer language switcher that preserves the current path.
- **Faster Chrome extension side panel handoff.** When a question asked from the Chrome extension starts a new conversation, the web app adds and opens that conversation immediately without waiting for a full list refresh, and reports the active Space to the extension so new questions target the Space you are viewing. (The Chrome extension package ships on its own schedule.)

## CLI and daemon

- **Pull request activity reporting for ACP agents.** ACP runtimes (Antigravity, Grok, OpenCode, Cursor, Kimi) now report `gh pr create` calls as `Opened pull request` Channel activity and auto-subscribe the conversation to pull request updates, matching Codex and Claude Code.
- **Trusted rules preserved on ACP resume.** Resuming or restarting an ACP session (`session/load` and its fallback to `session/new`) now retains trusted rules instead of dropping them.
- **Connector event discovery in CLI.** `xmatrix connector list` now displays each connected app's available event kinds and payload fields alongside its actions.
- **Unified quota refusal attribution.** The daemon now forwards raw quota refusal reset times and fresh provider readings so the Hub attributes quota windows and holds consistently from a single protocol implementation.

## Hub and automation (already live)

- **Norn 1 events and Space libraries.** Page-hosted Norn programs support the `Events` capability, GitHub and Gmail event libraries, Page-based Space libraries, and versioned `norn 1 run` headers. Outside-event deliveries are recorded durably per program so a blocked program cannot stall sibling programs or webhook processing.
- **Quota, WebSocket, Gmail, and App Store Connect reliability.** Quota waiter recovery uses per-pool locks and durable resumable reconciliation so exhausted sibling pools cannot starve recovered pools; WebSocket hibernation attachments enforce V8 structured-clone size limits before serializing; temporary Gmail upload snapshots use durable cleanup leases; and App Store Connect listings support resumable pagination cursors and frozen submission approvals.

## Compatibility and updating

- Run `xmatrix update` on each machine to update the CLI and daemon from `4.9.2` to `4.10.0`. No manual migration is needed.
- The live Hub already supports this website and CLI release.

## Known limitations

- Windows CLI binaries are not yet Authenticode-signed.
- Desktop (`4.9.1`), Android (`4.6.2`), and iOS (`4.0.4`, waiting for Apple App Review) have separate release schedules and are unchanged in this release.
