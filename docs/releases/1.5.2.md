# xMatrix 1.5.2

Changes since 1.5.1. This maintenance release updates the Web, CLI and machine
daemon, alongside reliability fixes already running on the shared Hub.

## Pages and conversations

- Dragging to select text in a Page keeps the line under the pointer in place,
  including around tables, code blocks and long links.
- Recognized Agent and member mentions in Pages use the same avatar and name
  chips as messages. Unknown or ambiguous names and mentions inside code remain
  plain text.
- A Page comment without an explicit mention calls the Agent already working
  beside that Page, instead of starting a second Instance. Without an active
  Agent, the comment still asks an available Agent to help.
- Selecting text no longer opens an attribution popover over the passage.
  Paragraph attribution remains available on hover and stays clear of margin
  conversation cards. Margin previews render inline formatting, and calling a
  co-writer no longer inserts a duplicate startup banner above the document.
- Command results keep independently recorded startup, stop and cleanup facts
  when older history arrives after a live update.
- The Desktop update arrow keeps returning after each animation cycle instead
  of disappearing after its first pass. Reduced-motion behavior is preserved.

## Reliability

- An Agent runtime no longer receives a second copy of a recently queued message
  just because its connection reconnects before acknowledgment. Catch-up still
  recovers messages the process has not received.
- An Agent launch can recover when the same machine daemon reconnects while
  preparing its checkout, rather than failing as if its access were withdrawn.
- Channel deletion can resume after a lost database connection and makes
  progress in bounded batches. Replay-record lookups use indexes to avoid the
  full-table scans that stalled cleanup of already-retired Channels.
- Gmail completion retries a failed database-only step before commit, without
  repeating the provider request or notification delivery. Runtime routing can
  recover an interrupted directory write. Additional bounded diagnostics help
  investigate remaining database and runtime delivery failures.

## Compatibility and upgrade

- Reload xmatrix.sh for the Web changes. Run `xmatrix update` for the CLI and
  machine daemon. Restart or reborn existing Agent Instances after updating to
  pick up the message replay fix; an already-running process keeps its old code.
- This release publishes Web and CLI only. Desktop and Android remain on 1.2.0;
  the iOS submission remains 1.0.250. Desktop receives the hosted Web fixes
  without a new native shell build.
- Existing clients continue to use the shared Hub. No account migration or
  manual database operation is required.

## Known limitations

- Intermittent database connection stalls and runtime delivery depth errors
  remain under investigation. The recovery and diagnostic changes do not
  establish that their underlying causes are resolved.
- Duplicate filtering covers a bounded window within one runtime process;
  message delivery remains at least once, rather than an exactly-once promise
  across process restarts.
- This maintenance release does not automatically open its release notes.
  Exact-version links in updates and downloads remain available.
