# xMatrix 4.7.3

This update is the CLI and daemon (`4.7.3`, up from `4.7.1`). The website stays
on `4.7.2`, Android on `4.6.2`, Desktop on `4.0.0`, and iOS on `4.0.4`. Hub
changes in this batch are already live.

## CLI and daemon

- **Antigravity quota now includes the Gemini weekly window.** Cloud Code's
  quota summary omitted the native Gemini group unless requests carried a
  versioned CLI `User-Agent`, so only `Gemini · 5h` appeared alongside
  `Claude & GPT`. The daemon now sends `antigravity/cli/<version>` from the
  installed `agy` CLI (or `1.5.13` when unavailable), reporting both
  `Gemini · 5h` and `Gemini · 1w` together with the `Claude & GPT` windows.
- **The daemon keeps unconfirmed command results instead of a command journal.**
  `daemon-command-effects-v1.json` is removed. The Hub decides whether a
  command runs through admission; the daemon keeps only results it has finished
  and the Hub has not yet confirmed, one file per command under
  `daemon-command-results/`, deleted once confirmed. An unreadable result file
  is removed instead of vetoing later commands, and any legacy journal file is
  cleaned up automatically when the daemon starts.
- **Execution outbox lock files are released after delivery.** Lock files
  created while delivering Run reports are now removed once each report lands,
  preventing the outbox directory from filling up and rejecting new reports on
  long-running machines.
- **Pages can be searched, outlined, and read or edited by section.**
  `xmatrix page search <query>` finds pages across the Space,
  `xmatrix page tree --summaries` shows each page's summary line,
  `xmatrix page read --outline` and `--section <slug>` read only the structure
  or one section, and `xmatrix page edit --section <slug>` updates a single
  section without replacing the rest of the page.
- **Windows background spawns stay hidden and Supervisor recovers unreadable
  activation journals.** Background commands launched by the daemon on Windows
  no longer flash console windows. If a Windows Supervisor encounters an
  unreadable `activation-journal.json` and `.previous` image, it sets both
  files aside (`*.unreadable-<timestamp>`) and falls back to starting its own
  release instead of exiting without a daemon.

## Compatibility

- Run `xmatrix update` on each machine to upgrade the CLI and daemon from
  `4.7.1` to `4.7.3`. Legacy `daemon-command-effects-v1.json` files are removed
  automatically on daemon restart; no manual migration is required.
- The running Hub already supports every CLI command in this release, including
  page search and section reads/edits.

## Known limitations

- Windows CLI binaries are not yet Authenticode-signed, so the Windows
  Supervisor recovery path cannot complete signature verification on current
  Windows installations (which run `xmatrix.exe daemon` directly from the
  scheduled task).
- The website, Android, Desktop, and iOS keep their current versions (`4.7.2`,
  `4.6.2`, `4.0.0`, and `4.0.4`).
