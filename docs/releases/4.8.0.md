# xMatrix 4.8.0

This update is the website (`4.8.0`, up from `4.7.4`) and the CLI and daemon
(`4.8.0`, up from `4.7.4`). Android stays on `4.6.2`, Desktop on `4.0.0`, and
iOS on `4.0.4`. Hub and connector changes listed below are already live.

## Website

- **Chrome extension side panel support.** The web app now runs inside the
  xMatrix Chrome extension side panel beside any web page. Selected passages
  from a page wait until the session and Space are ready before quoting into
  the active conversation or starting a new discussion, conversations opened by
  the extension load directly in the panel, an expired panel token prompts to
  sign in again in place, and the privacy policy covers the extension's side
  panel.
- **Stale builds reload automatically without losing drafts.** When a newer web
  deployment ships while a tab is open, the app refreshes cleanly instead of
  blocking work with a modal, keeping any unsent composer draft intact.
- **Mobile Handoff and Stop confirmations stay tappable.** Tapping a second
  confirmation button on iOS WebKit or narrow phone screens no longer collapses
  the controls on blur or lets the Agent avatar cover the Handoff and Stop
  buttons.
- **Steadier opening scroll in conversations.** Scrolling while a conversation
  is finishing its initial render no longer jumps away when the virtualized
  message list takes over from the opening tail.
- **Cleaner Agents matrix layout.** The Agents matrix page now uses wider outer
  margins and slightly tighter machine rows.
- **Inspectable sign-in failure output.** When a remote harness sign-in fails,
  the notice keeps the summary concise and folds the full process output into a
  collapsible **Command output** section.

## CLI and daemon

- **Reliable Google Antigravity remote sign-in and re-authentication.**
  Antigravity sign-in now runs `agy acp --login` over stdio instead of the
  earlier `agy -p /help` workaround. Both initial sign-in and **Sign in again**
  now produce a Google OAuth link reliably without a 60-second timeout or
  printing `/usage (quota)` help output as an error.
- **Clearer sign-in failure diagnostics.** When a harness sign-in command exits
  without printing a link, the daemon preserves the exit code, reports a plain
  explanation instead of surfacing the last line of stdout, and re-probes the
  harness's sign-in status. Re-authentication that exits non-zero is no longer
  reported as signed in just because a prior session still passes its status
  check.
- **Headless Windows login task.** On Windows machines where the user can edit
  the scheduled login task, setup and self-update now launch the daemon through
  `conhost.exe --headless` so a Windows Terminal window does not stay open, and
  self-update handoff and rollback resolve the CLI binary from that action.

## Connectors and Hub

- **Exclude an account from GitHub repository subscriptions.**
  `@github:subscribe:OWNER/REPO issues pulls except:LOGIN` filters out activity
  from a specific GitHub login (and `@github:unsubscribe:OWNER/REPO
  except:LOGIN` removes the exclusion), shown alongside subscription settings
  in the channel view.
- **Read-only Stripe connector inspection actions.** Agents can now inspect
  connected Stripe account data through read-only connector actions.
- **Reliability and presence improvements.** Gmail attachment sends keep their
  result if post-send cleanup fails, late unanswered-start verdicts no longer
  penalize launches that already connected, and resting-presence reads send
  each distinct runtime catalog once per response.

## Compatibility

- Run `xmatrix update` on each machine to upgrade the CLI and daemon from
  `4.7.4` to `4.8.0`. No manual migration is needed.
- Remote sign-in for Google Antigravity via `agy acp --login` requires
  Antigravity CLI `1.5.0` or later (`agy update`).
- The running Hub already supports this CLI and website.

## Known limitations

- Windows CLI binaries are not yet Authenticode-signed.
- Android, Desktop, and iOS keep their current versions (`4.6.2`, `4.0.0`, and
  `4.0.4`).
