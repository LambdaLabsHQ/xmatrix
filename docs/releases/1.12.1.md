# xMatrix 1.12.1

This Web-only patch follows up 1.12.0's history-reading fix. CLI and Desktop
binaries remain at 1.12.0; Android and iOS binaries are unchanged.

## Keep reading while older messages arrive

A slow layout could still move the message you were reading when older history
was added and you kept scrolling beyond the anchor's original ten-second
window. Active reader input now renews that bounded protection, so the anchor
continues to account for your own movement while the list settles. Passive
layout or compensation changes cannot keep it alive indefinitely; quiet
reading, leaving the conversation and replacing its history still release it.

The earlier fix alone did not cover this long-running case. This patch keeps
the same scroll-movement checks and adds coverage for continued input past
that original deadline.

## Apple sign-in diagnostics

The Web retains the native Apple sign-in failure boundary for troubleshooting,
including errors raised before a token reaches the Hub. This improves the
evidence available for an unknown authorization error; it does not establish
or fix Apple's underlying failure. Cancellation remains quiet and Apple
authorization is not automatically replayed. Rich native error categories
require an iOS shell that supplies them; this release does not update that
shell.

## Update and verification limits

Reload the Web to receive the changes. Desktop loads the updated stable Web;
no client reinstall or data migration is needed for this patch. The native
installation fixes and upgrade actions remain described in
[1.12.0's release notes](https://xmatrix.sh/releases/1.12.0).

Existing physical-device, first-machine onboarding and dedicated-identity
verification requirements remain open.
