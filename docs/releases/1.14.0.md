# xMatrix 1.14.0

This Web release adds compact previews for Page edits in Channels, keeps
explicitly opened mention details from disappearing, and improves Page sharing,
connector-command presentation and iOS Back behavior.

## Page edits fold into a readable preview

Messages that change a Page now show a compact summary: the Page name, changed
sections and counts of lines added or removed. Two short previews lead with
the current text and focus on the words that changed. Expand the card to read
all changes by section, or use its separate Open page action to navigate.

## Mention details stay open after activation

Pressing Enter or clicking to keep a mention's details open now cancels an
earlier hover-close request. Previously, moving the pointer away could queue
a close that still fired after keyboard activation. Ordinary hover dismissal,
Escape, outside clicks and moving focus away retain their usual behavior.

## Page sharing explains access and gives you the right link

The Share pane opens below its button and separates who can read a Page from
who can change it. Existing publishing and Space-rule controls use consistent
switches, show pending requests and report failures inside the pane.

The in-app link and public link have separate copy actions, each with its own
confirmation. Access rules and approval requirements are unchanged.

## Connector commands keep their highlight

Commands containing mailbox addresses, URLs or Markdown punctuation retain
their command highlight instead of being split into ordinary Markdown links
or fragments. Later literal copies do not acquire a second command chip;
quoted, code and edited text keep their non-executing presentation.

## iOS Back avoids replaying the current screen

When the iOS app delivers a native Back gesture, the Web commits the parent
screen or closes the overlay synchronously. It no longer starts a second Web
transition underneath the native animation. Chevron, Android and browser Back
keep their existing Web transitions. This is a hosted Web correction, without
a new native app build.

## Update and verification limits

Reload the Web to receive the changes. Desktop loads the updated stable Web;
no client reinstall or data migration is needed. CLI/daemon and Desktop
binaries remain at 1.12.0, Android at 1.2.0 and stable iOS at 1.11.1.

Short stalls while loading older Channel history remain a separate performance
investigation. Dedicated-identity sign-in, first-machine onboarding,
physical-device and isolated multi-party or payment verification requirements
remain open.
