# xMatrix 4.0.4

This update does not change the website, the iOS app, the CLI, or the
Desktop app. The CLI and daemon stay on 4.0.1. The Desktop app stays on
4.0.0. Android is unchanged.

## The rejected iPad recording

Apple's crash logs for iOS 2.2.0 name why that recording stopped. The
app started a video, which needs the microphone, and the reviewed build
had no microphone usage description. iOS stopped the app for the missing
description. xMatrix 4.0.3 already includes that description. Naming the
cause did not require another recording on a physical iPad.

## Updating and known limits

The 4.0.3 iOS build was uploaded and was not submitted to App Review.
Apple's rejection of iOS 2.2.0 is still open. This document does not say
a new build has been submitted to App Review, and it does not say the
rejection is resolved. A TestFlight build is not App Store acceptance.

A successful send of a large Gmail draft is still not confirmed end to
end. If removing its staged copy fails, a send the provider already
accepted can still show as an error; check the mailbox before sending
again. The Mac full-screen sign-in fix and the Windows daemon-detection
fix still await acceptance on the affected computers.
