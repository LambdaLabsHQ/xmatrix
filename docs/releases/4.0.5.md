# xMatrix 4.0.5

This update is the website. Refresh it to pick the changes up. The CLI and
daemon stay on 4.0.1. The Desktop app stays on 4.0.0. Android is unchanged.
This release does not submit a new iOS build. iOS 4.0.4 stays the build in
App Review.

## App Store Connect

The App Store Connect connection on the website now has a private App Review
setup field, and a channel can turn on subscription and in-app purchase
review. The Hub already accepted these settings. Website 4.0.4 did not show
them, so the stable website could not save or select them.

The private setup stays in the connection's credentials. It names the app,
the review contact, and, only when a demo account is required, that
account. Applying it updates one editable version and checks the saved
values. It does not submit that version to App Review, and it does not put
the account in a channel.

Subscription and in-app purchase review starts from the channel option.
The first observation is a baseline. Later changes are announced.

## Updating and known limits

A successful send of a large Gmail draft is still not confirmed end to
end. If removing its staged copy fails, a send the provider already
accepted can still show as an error; check the mailbox before sending
again. The Mac full-screen sign-in fix and the Windows daemon-detection
fix still await acceptance on the affected computers.

iOS 4.0.4 is in App Review and is not an App Store release. This document
does not say that review is approved, and it does not say the earlier
rejection is resolved.
