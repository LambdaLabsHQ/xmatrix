# xMatrix 3.1.2

The public website now declares the right language and sharing address before
browser scripts run. Phone notifications also open conversations without
stacking one whole page over another.

## Public pages and documentation

The Chinese homepage now declares Chinese in its initial HTML, matching its
language links even with JavaScript disabled. Download, legal and versioned
release pages now share their own canonical address instead of the old
domain's homepage. The Calendar connector guide opens its working repository
document.

Both xmatrix.page and xmatrix.sh continue to serve the public website, with
canonical addresses on xmatrix.page. App and sign-in addresses keep their
existing redirects. These changes correct page metadata and a broken link;
they do not establish that search engines have recrawled or reindexed the site.

## Phone navigation

Opening a notification while the Channel list is visible slides its
conversation in, just like tapping a row. From another conversation, search
or a dock tab, it replaces the screen in place. Back returns to the Channel
list. Dock tabs retain their own sliding motion, without an additional
whole-page transition over the previous screen.

## Shared service improvements already available

New Agent Runs receive their conversation's linked Pages in their starting
context, including the revision needed for edits. A Page that exceeds the
context budget is identified for an explicit read rather than truncated.
Scheduled conversations also receive a name from their first message.

The App Store Connect connector can list one-time In-App Purchases and submit
ready purchases for review through an app version, alongside its existing
subscription support. Channel attention counts also use more focused database
queries. These shared Hub changes have already been released independently of
this Web update.

## Compatibility and scope

Refresh the website or reopen the app to load the updated Web. No data
migration, account changes or reinstall is required. This release updates Web
only: CLI/daemon and Desktop binaries remain at 3.1.0; iOS and Android binaries
are unchanged. Native Desktop fixes awaiting a client release are not included.
The settings-card limitations documented in 3.1.0 still apply. This release
does not address unverified audit notices about description length or slow
pages, and does not change the site's robots policy.
