# xMatrix 4.0.1

This update keeps your place in a conversation, names pages from the
document itself, and makes an idle computer quieter. It updates the website
and the CLI/daemon. The Desktop app stays on 4.0.0. This release does not
submit a new iOS build to the App Store.

## Reading and composing

Opening a Needs-you conversation, or jumping to a message, keeps that
message where it landed while private result cards above it finish loading.
The position holds until you touch, scroll, click, type, jump again, or
switch conversations. A conversation also stays put when a row above the
screen changes height, including while you scroll.

Files stay attached when their picture syntax sits inside a code example,
HTML, or beyond a folded preview. A picture the message actually shows is
not listed again as a file. Picture syntax written as an example stays in
the composer and in the sent message. Editing text before a quote no longer
leaves that quote's remove control at its old position. A reply that quotes
a whole message uses the same yellow slip as a quoted passage.

On a phone, a conversation uses one tinted header, and the list under the
channel sign reserves the room its rows will occupy. The header takes its
tone from the same summary and linked page as the plaque beneath it.

## Pages, schedules, and Agents

A page's name is the first top-level heading in the document, wherever that
heading stands. A document without one is still called Untitled. Renaming
rewrites that heading. An open comment thread in the margin no longer
covers its own words with the conversation composer.

A schedule shows what its ten latest runs produced: pull requests, page
edits, nothing, a failed start, or still running. The same summary is on
the schedule row, in its detail, and in `xmatrix page automation list` and
`page read`. Changing a repeating schedule into a one-time reminder is not
marked done by runs from the old repeat.

Opening a Channel loads 5-hour and 1-week usage again for Agents that have
been idle. A Codex CLI older than 0.141.0 is named, with its computer and
how to update it, instead of being started. A machine's registration name
follows that registration's own rename, and the same view includes its
saved goal and current Git branch.

## The computer that stays connected

Update the CLI and daemon together to get these fixes. An idle daemon no
longer wakes xMatrix every minute or writes a load sample on that timer. It
stays present through the existing heartbeat. A daemon that goes silent is
shown offline, and its load history stays on the computer until the next
report. A reconnect keeps the new machine credential: a queued refresh from
an older connection is discarded instead of rolling that credential back.

On Windows, a Machine can check out a repository whose path is longer than
the legacy path limit.

`xmatrix page edit` accepts the page's own text, or everything `xmatrix
page read` prints. The read-out header is left out. A file that is only
that header is refused.

## Connection recovery and Gmail

When a recorded database disconnect uses up its one fresh-connection retry,
xMatrix reports the action as temporarily unavailable instead of a permanent
session failure. The same one-retry recovery applies to system judgments and
to listing transfer proposals. This does not remove the underlying
disconnects.

A Gmail draft's approval card lists real attachments separately from inline
signature images, and says when there are no attachments. A card full of
signature logos is not shown as a stack of documents.

## Updating and known limits

Refresh the website, or install the CLI/daemon update, to pick this up.
Desktop stays on 4.0.0. Android is unchanged. Accounts and saved content
need no migration. Scripts that start Agents must keep using the explicit
launch option introduced in 4.0.0. This release does not turn on an
automatic release-notes popup.

This release does not submit iOS to App Review. The App Store build already
waiting for review stays as it is. A new submission is waiting on updated
review instructions and an in-app login recording. Submitting now would
replace Apple's notes with the older browser-login text.

Daemons that are not updated keep their previous once-a-minute check-in.
The Mac full-screen sign-in fix and the Windows daemon-detection fix still
await acceptance on the affected computers. A successful send of a large
Gmail draft is still not confirmed end to end. If removing its staged copy
fails, a send the provider already accepted can still show as an error;
check the mailbox before sending again. Existing settings-card limits
remain. An out-of-order presence snapshot can temporarily omit an Agent
avatar without stopping its Run. A paged App Store Connect listing can omit
later pages or reject a named item; a default listing is not proof of a
complete set.
