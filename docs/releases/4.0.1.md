# xMatrix 4.0.1

This update keeps the message you jumped to in view, preserves files that a
message has not actually displayed, and improves recovery from recorded
database disconnects. It also brings the current native iOS improvements to
the next App Store submission.

## Reading and composing messages

- Opening a Needs-you conversation or jumping to a message keeps that message
  where it landed while private result cards above it finish loading. The
  position is held until you interact, jump again or switch conversations.
- Files remain attached when their picture syntax is inside a code example
  or beyond a folded preview. A displayed Markdown image reference no longer
  causes the same file to appear twice. Image placement and the remaining
  file list now follow what the message actually renders.
- Editing text before a quoted passage no longer leaves the quote's remove
  control pointing at its old position.

## Connection recovery

The shared Hub retains the recorded reason for a database connection ending.
When its one fresh-connection retry is exhausted, a recorded disconnect is
reported as temporarily unavailable instead of a permanent session failure.
This improves recovery and diagnosis; it does not establish or fix the
underlying cause of the outage or database lock contention. Routine daemon
commands also avoid repeatedly transferring the computer's full inventory.

## iOS

The new native build includes the Channels/Pages tab animation fixes and
support for up to 120 Hz on compatible displays. Connected conversations slide
in from their list. The tab animation has been accepted on a physical iPhone;
other devices and refresh-rate behavior have not all been independently
verified. The app requires iOS 26 or newer.

The stable iOS build is submitted to App Review when Apple's current review
state permits. A TestFlight build or an accepted submission does not mean the
app is publicly available in the App Store. An older version already in
review is preserved; an older version still waiting may be replaced, carrying
its subscription items into the new submission.

## Updating and known limits

Refresh the website or reopen the app for the Web fixes. CLI/daemon and
Desktop packages remain at 4.0.0; Android's native package is unchanged.
Accounts and saved content need no migration. Scripts that start Agents must
continue to use the explicit launch option introduced in 4.0.0. Release notes
remain available from update and download links; no additional automatic
popup is enabled.

The original Mac full-screen sign-in and Windows daemon-detection fixes still
await acceptance on the affected computers. A successful real Gmail send with
large attachments remains unconfirmed. Existing settings-card limits remain,
and out-of-order presence snapshots can temporarily omit an Agent avatar
without stopping its Run. Paginated App Store Connect collections can omit
later-page items or reject a named item; default listings and submissions are
not proof of a complete set. App Review access instructions and the replacement
in-app-login recording remain separate review-material work, and are not
claimed complete by this release.
