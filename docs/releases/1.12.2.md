# xMatrix 1.12.2

This Web-only patch follows up the Page-opening checks in 1.12.1. CLI and
Desktop binaries remain at 1.12.0; Android and iOS binaries are unchanged.

## Page attribution starts from the current revision

Opening a Page now waits for its live session to identify the current revision
before reading who wrote its text. Moving to another Page clears the previous
Page's revision first. This avoids an early read against an unknown revision
and a second request when the live head arrives.

Paragraph attribution and author highlights continue to follow the document
on screen while people edit it.

## Update and verification limits

Reload the Web to receive the changes. Desktop loads the updated stable Web;
no client reinstall or data migration is needed. Native installation fixes
remain described in [1.12.0's release notes](https://xmatrix.sh/releases/1.12.0),
and the long-running history-reading correction is covered in
[1.12.1's release notes](https://xmatrix.sh/releases/1.12.1).

Existing physical-device, first-machine onboarding and dedicated-identity
verification requirements remain open.
