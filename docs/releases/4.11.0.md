# xMatrix 4.11.0

This release updates the website (`4.11.0`, up from `4.10.0`), the CLI and daemon (`4.11.0`, up from `4.10.0`), and the iOS app (`4.11.0`, up from `4.0.4`, submitted to Apple App Review). Desktop (`4.9.1`) and Android (`4.6.2`) keep their current versions. Hub and automation improvements listed below are already live.

## Website

- **Quieter first-message Agent choice.** Under a new conversation's first message, the card of Agent pills is replaced by a single line of text showing the Agent xMatrix picked, the remaining countdown, and **Change** / **Don't start** actions. Opening **Change** pauses auto-launch first so you are no longer racing the countdown, and lets you pick another Agent or send the summon to the composer with full parameter completion.
- **Inline workspace search chip editing.** Workspace search keeps its single-row inline filter chips while fixing deletion and overflow: press `Backspace` at the start of the query or use `ArrowLeft` + `Backspace`/`Delete` (or focused chip `×` buttons) to remove filters without clearing typed text. Long filter chips now truncate cleanly on desktop and mobile.
- **Connected account labels.** Connected app entries now display which account or workspace a connection reached (`Connected · <account> · via …`) across Google, Linear, Slack, Notion, and Bing after a connection check.
- **Original-aspect video attachments and faster public pages.** Inline conversation videos now render at their natural aspect ratio instead of forcing a 16:9 letterboxed box. All localized public pages across six languages (home, download, support, guides, and competitor comparisons) are prerendered at build time with valid structured data and direct app links.
- **Browser page context in conversations.** Messages sent from the Chrome side panel show the active page beneath the message so people and Agents share page context.

## CLI and daemon

- **Browser page context for Agents.** When a message comes from the Chrome side panel, the CLI runtime passes the active page title and URL to the Agent with `xmatrix browse` instructions so Agents can read the page beside the side panel (`--conversation` and `--tab` remain available with owner approval).
- **Lighter conversation lookup and file uploads.** `xmatrix channels --find <words>` now filters matching Channels on the Hub instead of downloading the entire Space catalog, and attaching a file queries only the target Channel's family.

## iOS

- **Native composer attachment picker.** Tapping the paperclip button morphs the composer capsule upward in place to offer Photo Library, Take Photo or Video, and Choose Files, opening native iOS photo, camera, and document pickers directly instead of a detached WebKit popover, with flicker-free close transitions and immediate work-dock clearance.
- **Native panels, unified navigation, and lower idle overhead.** Added WKWebView alert, confirm, and prompt panel handling so confirmation actions work reliably on iPhone and iPad, updated the mobile tab bar for the unified Agents × Machines matrix, reduced idle GPU compositing and 120Hz animation overhead, and updated App Store subscription disclosures.

## Hub and automation (already live)

- **Pre-approved scheduled app actions in Norn.** Page-hosted Norn programs can prepare connected-app actions (including X posts and videos) for upfront Space admin approval and execute them on schedule without starting an Agent.
- **One-step X video posts and Google Play products.** `@x:publish_video` uploads and publishes an MP4 attachment under a single approval, and `@googleplay:one_time_product` creates and prices a one-time in-app product in one command.
- **Reliability and database efficiency.** New users without connected Agents now receive setup guidance in their welcome conversation, restoring an unchanged `norn run` block on a Page resumes its program, and narrowed PostgreSQL queries reduce read egress across Page access checks, Page activity, Agent catalogs, and attention snapshots.

## Compatibility and updating

- Run `xmatrix update` on each machine to update the CLI and daemon from `4.10.0` to `4.11.0`. No manual migration is needed.
- iOS `4.11.0` is submitted to Apple App Review and will reach the App Store once approved.
- The live Hub already supports this website, CLI, and iOS release.

## Known limitations

- Windows CLI binaries are not yet Authenticode-signed.
- Desktop (`4.9.1`) and Android (`4.6.2`) have separate release schedules and are unchanged in this release.
