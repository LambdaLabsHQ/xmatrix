# xMatrix 4.11.0

This release updates the website (`4.11.0`, from `4.10.0`), CLI and daemon (`4.11.0`, from `4.10.0`), and iOS app (`4.11.0`, from `4.0.4`, submitted to Apple App Review). Desktop (`4.9.1`) and Android (`4.6.2`) keep their current versions. Hub and automation improvements below are already live.

## Website

- **Quieter first-message Agent choice.** A new conversation's first message now shows a single line of text with the picked Agent, countdown, and **Change** / **Don't start** actions instead of a pill card. Opening **Change** pauses auto-launch first so you are not racing the countdown, and lets you pick another Agent or move the summon into the composer with full completion.
- **Inline workspace search chip editing.** Active search filter chips stay in one inline row, truncate long labels cleanly on desktop and mobile, and delete via `Backspace`, `ArrowLeft` + `Backspace`/`Delete`, or focused `×` buttons without clearing typed search text.
- **Connected account labels.** Connected apps show which account or workspace a connection reached (`Connected · <account> · via …`) across Google, Linear, Slack, Notion, and Bing after a check.
- **Natural-aspect videos and prerendered public pages.** Inline videos render at their original aspect ratio instead of a fixed 16:9 box. All six-language public pages (home, download, support, guides, and competitor comparisons) are prerendered at build time with valid structured data and direct app links.
- **Browser page context.** Messages from the Chrome side panel show the active page beneath the message.

## CLI and daemon

- **Browser page context for Agents.** On messages from the Chrome side panel, the CLI runtime passes the active page title and URL with `xmatrix browse` instructions so Agents can read the page beside the panel (`--conversation` and `--tab` remain available with owner approval).
- **Lighter Channel lookup and uploads.** `xmatrix channels --find <words>` filters Channels on the Hub instead of downloading the full catalog, and file uploads query only the target Channel's family.

## iOS

- **Native composer attachment picker.** Tapping the paperclip morphs the composer capsule upward in place to offer Photo Library, Take Photo or Video, and Choose Files, opening native iOS photo, camera, and document pickers directly instead of a detached WebKit popover, with smooth close transitions and immediate work-dock clearance.
- **Native dialogs, unified navigation, and lower idle overhead.** Added WKWebView alert, confirm, and prompt panel handling, updated the mobile tab bar for the unified Agents × Machines matrix, reduced idle GPU compositing and 120Hz animation burn, and updated App Store subscription disclosures.

## Hub and automation (already live)

- **Pre-approved scheduled app actions in Norn.** Page-hosted Norn programs can prepare connected-app actions (including X posts and videos) for upfront admin approval and run them on schedule without starting an Agent.
- **One-step X video posts and Google Play products.** `@x:publish_video` uploads and publishes an MP4 under one approval, and `@googleplay:one_time_product` creates and prices a one-time in-app product in one command.
- **Reliability and database efficiency.** New users without Agents get setup guidance in their welcome conversation, restoring an unchanged `norn run` block resumes its program, and narrowed PostgreSQL queries cut read egress across Page access checks, Page activity, Agent catalogs, and attention snapshots.

## Compatibility and updating

- Run `xmatrix update` on each machine to update CLI and daemon from `4.10.0` to `4.11.0`. No manual migration is needed.
- iOS `4.11.0` is submitted to Apple App Review and will reach the App Store once approved.
- The live Hub already supports this release.

## Known limitations

- Windows CLI binaries are not yet Authenticode-signed.
- Desktop (`4.9.1`) and Android (`4.6.2`) are unchanged in this release.
