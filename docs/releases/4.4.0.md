# xMatrix 4.4.0

This update is the website and the CLI/daemon. The Desktop app stays on 4.0.0,
the Android app on 4.1.0 (still in Google Play review), and iOS on 4.0.4. Hub
changes are already live. The CLI/daemon was last released as 4.2.1, so its
changes since then are included here.

## Quota is tracked per model

Some providers limit one model separately from the rest of the account, for
example a weekly limit for Fable on a Claude subscription. xMatrix now keeps
those limits apart:

- When one model's quota is used up, the Machine still takes work on the
  account's other models. Before, a used-up model could make the whole Machine
  refuse new work.
- An Agent whose turn stops because its model's quota is used up continues
  right away on another model of the same harness that still has quota, and
  goes back to its original model once that model has quota again. If no other
  model is available, it waits for the reset as before.
- A request that names a used-up model says when that model's quota resets.
- Quota bars name a model's own limit next to the account's, for example
  `Fable · 1w`.

The daemon reports these per-model limits from 4.4.0 on. Update the daemon on
each Machine to get them; an older daemon reports account limits only.

## Asking, delegating and calling off

- A question an Agent asks you with `xmatrix confirm`, `choose` or `ask` now
  shows as a single card that names the Agent that asks (`claude:2 asks`).
  When the question has a default, the card says what happens without an
  answer, and the closing note says what was recorded.
- **Delegate…** on a request card hands the request to someone who can answer
  it for you: an Agent, an Agent already in the conversation, or another
  member. Your card closes with the reason you gave; **Take back** returns it
  to you while it is still open. If the person or Agent you chose gives it
  back, it returns to you. Agents can do the same with `xmatrix delegate`.
- An Agent that asked a question by mistake can withdraw the card with
  `xmatrix cancel`; the card then says it is no longer asked.

These commands come from the Hub, so they work with any current CLI.

## CLI

- `xmatrix page automation` is removed. Recurring work, reminders and
  event-driven work are Norn programs (<https://xmatrix.sh/docs/programs>).
  `xmatrix page read` no longer prints an `automations:` line.

## Fixes

- The Privacy Policy and other legal pages keep their header below the status
  bar on iPhone, and their links no longer overlap the clock.
- Fewer short failures when reading pages, Machine names and programs while
  the database is briefly slow.
