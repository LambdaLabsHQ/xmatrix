# xMatrix 1.11.1

This release updates the iOS app for the stable service. The stable Web remains
at 1.11.0; CLI/daemon, Desktop and Android binaries are unchanged.

## iOS

- The App Store build opens the stable Web at `https://xmatrix.sh/app`.
  TestFlight beta builds use the separate beta Web. Each build trusts only
  its own Web origin for in-app navigation and native bridge calls.
- The edge swipe asks the current page to go Back to its parent screen or
  close its top layer, instead of replaying WebKit browser history.
- Opening a notification passes its destination to the running page before
  falling back to a full page load.
- Sign-in stays inside the app. The current stable Web includes the Page,
  conversation and connected-app improvements described in
  [1.11.0](https://xmatrix.sh/releases/1.11.0).

## Service reliability

The shared service can retry a lost public-key or account-directory database
read once on a fresh connection. Signature and access checks stay in force;
a second failure still surfaces. This does not diagnose the transport stall.

## Compatibility and availability

- No data migration or CLI update is required for this iOS update.
- A processed TestFlight build is not an App Store approval. Availability to
  App Store users depends on Apple's review; a previous pending review may
  defer the new submission.
- Simulator checks do not replace real-device checks of gestures,
  notifications, sign-in callbacks and media. Provider sign-in and full
  multi-Agent recovery retain their separate verification needs.
- New Page edits that have not synchronized can still be interrupted by
  closing the app or by a first-sync handoff exceeding 15 seconds.
