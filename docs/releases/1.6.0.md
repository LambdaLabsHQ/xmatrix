# xMatrix 1.6.0

Changes since 1.5.2. This release updates the Web, CLI and machine daemon,
with reliability improvements already running on the shared Hub.

## Pages and conversations

- Pages show their authors beneath the title, ordered by how much of the
  current text each wrote. Point at an author to highlight their words; the
  byline follows live edits, including words moved or removed before saving.
- The Page header is quieter: revision labels, presence faces and discussion
  counts give way to the author byline. Connection, offline and read-only
  notices still appear when needed. To call an Agent on desktop, mention them
  in the document. Agents can still manage schedules through the CLI.
- Video and audio attachments show download progress, including bytes and a
  percentage when the size is known, in both messages and the full-screen
  viewer. Large videos no longer look like an unexplained black frame while
  downloading.
- Conversation text has more room between lines and blocks. Share buttons use
  the same icon throughout the interface.
- Sending a message keeps a smooth upward motion as the draft, server copy and
  late controls change the layout. An Agent joining a Channel no longer makes
  its work dock briefly disappear or shift the conversation underneath it.
- A first message in a Space without an enabled Agent gets an explanation and
  setup guidance instead of leaving the sender without an answer.

## Attachments and runtime controls

- `xmatrix send --file` works from a person's terminal as well as an Agent Run.
  Sending the same attachment again reuses the existing content reference
  instead of failing when the bytes are already stored for that owner.
- Runtimes that advertise custom commands separately from their model catalog,
  including Cursor, retain the available model and effort controls in command
  and Agent mention menus.
- Machine reconnection attempts have bounded waits and report each failure's
  current reason. A first successful connection after a failed attempt clears
  the reconnecting state. A daemon that remains disconnected for ten minutes
  restarts its runtime and re-adopts running Agents through the normal path.
- Daemon connection logs include UTC timestamps and more useful failure
  references; unmanaged daemon updates preserve their diagnostic logs.

## Shared Hub reliability

- Python-style MCP clients can reach the Hub's OAuth challenge without being
  rejected by the browser integrity check. Normal authentication is required.
- Sentry event recovery defers an app whose processing capacity is temporarily
  locked, then retries through its scheduled wake instead of failing the claim.
- Missing Spaces return a clear not-found response. A permanently purged Space
  still refuses restoration. Failure notices remain writable, and bounded
  diagnostics better distinguish database, runtime, credential and harness
  release-watch failures without exposing credentials or message content.

## Compatibility and upgrade

- Reload xmatrix.sh for the Web changes. Run `xmatrix update` for the CLI and
  machine daemon. Restart or reborn existing Agent Instances after updating
  when they need to pick up the new runtime code.
- This release publishes Web and CLI only. Desktop and Android native shells
  remain on 1.2.0; the iOS submission remains 1.0.250. Desktop receives the
  hosted Web changes without a new shell build.
- Existing clients continue to share the same Hub. No account migration or
  manual database operation is required.

## Known limitations

- Media still downloads in full before playback; the progress display does not
  add streaming playback.
- Intermittent database, runtime delivery and credential verification failures
  remain under investigation. New diagnostics do not establish that their
  underlying causes are fixed. Other daemon requests outside the reconnect
  path retain their existing timeout behavior.
- The MCP edge fix verifies access to OAuth; a particular third-party client's
  complete authorized read/write flow still needs that client's own validation.
- This release does not automatically open its notes. Exact-version links in
  updates and downloads remain available.
