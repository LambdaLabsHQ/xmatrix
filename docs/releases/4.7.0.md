# xMatrix 4.7.0

This update is the website (`xmatrix.sh`, up from `4.6.3`) and the CLI/daemon
(`4.7.0`, up from `4.6.1`). Android stays on `4.6.2`, Desktop on `4.0.0`, and
iOS on `4.0.4`. Hub changes listed below are already live.

## Pages and conversations

- **Unlink a page from a conversation.** A page's header card in a conversation
  now offers **Unlink from this conversation**, and the CLI adds
  `xmatrix page unlink <page-id>`. Unlinking removes all links between the two,
  stops co-writing wakes, and prevents future reads, edits, or mentions from
  linking them again until someone links them explicitly.
- **Full `@` and `#` completion in page comments.** Commenting on a selected
  passage on a Page now gets full Space context—`@` lists every Agent, machine,
  and launch condition the Space can start, and `#` lists channels and
  pages—rendered in the page's paper-menu style. Picking an Agent, `@auto`, or
  `@machine:…` starts a new discussion carrying that pick instead of routing to
  an Agent already at work on the page.
- **Runtime checklists retired from conversations.** Conversations no longer
  display per-runtime plan checklists or plan lines in the work dock; progress
  is carried by each Agent's own status messages together with pull request, CI,
  and merge updates.
- **Dock trace panel.** Clicking an Agent capsule in the conversation dock now
  morphs the capsule upward and right into its Trace panel so you can inspect
  live activity without covering the conversation in a centered modal.

## System Overview and workspace (Web)

- **System Overview desktop matrix.** The unified Agents view is now titled
  **System Overview** and spans the full panel with balanced horizontal padding,
  simplified header typography, aligned edges across headings and rows,
  single-line quota bars for scoped windows (such as `Auto · 1mo` and
  `Fable · 1w`), clearer contrast between `Ready`, `Off`, and `+` cells, and
  sticky-column scrolling cues.
- **Quieter mobile Agents matrix.** Missing agents render as quiet dots unless
  at least two of your own machines have them installed, multiple agents needing
  attention on one machine are named together without shrinking the machine
  name, and strained CPU/memory/disk readings appear alongside their bar.
- **Default model dropdown.** Agent settings and Space registered locations now
  offer a menu of the harness's reported models (alongside **Harness default**
  and **Other model…** for custom names) instead of a free-text input.
- **Space usage breakdown icons.** Settings → Billing now displays canonical
  Agent, app connector, and member icons beside each usage row.

## CLI and daemon

- **Antigravity quota reporting.** The daemon and ACP runtime now read Google
  Antigravity (`agy`) model-pool quotas (`Gemini` and `Claude & GPT`) and
  preserve scoped trace usage.
- **ACP and Antigravity waiting states.** Long-running in-turn tool calls (past
  15 seconds) and cross-turn Antigravity background tasks now report `waiting`
  instead of staying `busy` or `idle`, preventing premature idle sleep and
  resuming cleanly when background work finishes.
- **Windows daemon startup and watchdog resilience.** When
  `Register-ScheduledTask` is denied on Windows, `xmatrix setup` falls back to a
  per-user logon entry (`HKCU\...\Run`), starts the daemon directly, and cleans
  up both entries on `xmatrix setup uninstall`. During self-update, if an
  administrator-owned `xmatrix-daemon` task cannot be modified, the CLI leaves
  it untouched and registers a per-user minute watchdog
  (`xmatrix-daemon-watchdog` or `xmatrix-daemon-user-watchdog` via
  `conhost.exe --headless`), reporting watchdog readiness in Machines.
- **Clearer peer discovery in `xmatrix list`.** `xmatrix list` now shows
  `@<name>:<instance>` addresses and channels, groups current-channel Instances
  first, and includes addressable resting peers (`sleeping`, `interrupted`,
  `waking`).

## Fixes

- **Green CI pass tick.** GitHub pull request slips now display a green tick
  when the latest CI checks passed, distinguishing passes from open or failing
  checks at a glance.
- **No single-item mention folding.** Open mention sections across all composers
  now show their last candidate directly instead of spending a "Show 1 more" row
  to hide it.
- **Parallel Agent lifecycle controls.** Stopping, reborning, or handing off an
  Agent from the conversation dock no longer disables lifecycle actions on other
  Agents while a request is in flight.
- **Addressable resting peers in `@` completion.** The Web `@` menu's **In this
  conversation** section includes sleeping, interrupted, and waking Instances
  while excluding failed or stopped ones.
- **Onboarding device detection.** Native iOS and Android wrappers are no longer
  misclassified as the desktop app, and narrow or touch-screen desktop browser
  windows keep desktop setup instructions.
- **Hub routing and control fixes.** Named summons to a billing-refused harness
  no longer strip all of its models under an account-level hold (per-model quota
  limits still apply), late or expired harness control switch results are
  ignored safely, and Agent Runs can unlink a page from their own conversation.

## Compatibility

- **Web:** updates automatically on reload.
- **CLI / daemon:** run `xmatrix update` to upgrade from `4.6.1` to `4.7.0`.

## Known limitations

- On Windows 10 builds prior to ConPTY (`1809`), where `conhost.exe` does not
  accept `--headless`, the per-user fallback watchdog cannot restart the daemon
  automatically.
- Desktop stays on `4.0.0`, Android on `4.6.2`, and iOS on `4.0.4`.
