# xMatrix 4.9.2

This release updates the xMatrix CLI and daemon.

## CLI and daemon

- **Antigravity quota reads through the native `agy` CLI.** The daemon and ACP runtime now query Google Antigravity model-pool quotas (`Gemini` and `Claude & GPT`, 5-hour and weekly windows) via `agy -p "/usage" --output-format json` instead of reading local OAuth token files or calling private Cloud Code endpoints directly. Quota reporting now works with system keyring sign-ins on macOS and Windows (`agy` 1.5+), preserves unrounded usage percentages, aborts quickly when signed out, invalidates cached readings after remote sign-in, and skips unsupported older `agy` versions. Set `XMATRIX_DISABLE_ANTIGRAVITY_QUOTA_PROBE=1` to disable Antigravity quota probing explicitly.
- **Partial page reads cannot overwrite a whole page.** `xmatrix page edit` now accepts only whole-page or single-section reads and refuses output from `--outline`, `--since`, or revision history before making a request.
- **Updated handoff syntax in CLI help.** `xmatrix send --help` documents parameterized handoffs (`@agent:1:handoff:@target`).

## Updating

- Run `xmatrix update` on each machine to update the CLI and daemon. No manual migration is needed.
- Website, Desktop, Android, and iOS have separate release schedules.
