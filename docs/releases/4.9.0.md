# xMatrix 4.9.0

This release updates the website, CLI, and daemon. The Hub already supports the features below.

## Connected apps

- **Switch, pause, or remove a connection.** Switch account opens the provider's sign-in or lets you replace saved credentials. Pause stops commands and Channel updates until you resume with the same account. Remove deletes the connection and its subscriptions after confirmation. Google connections offer Sign out in place of Pause. Apps that support multiple accounts still manage each account separately.
- **Use a saved Space secret for a connection.** Space admins can fill a credential field from an existing secret. xMatrix checks the connection without displaying the secret value.
- **Sign in to Bing Webmaster Tools.** You can connect or switch Bing accounts through Microsoft sign-in. Existing API-key connections continue to work.
- **Return to where you started signing in.** Connector sign-in started on the beta website returns there. Sign-in started from Desktop and reconnecting a specific X account retain their original destination and account, respectively.

## Website and CLI

- **Less background work on phones.** The mobile website pauses decorative animations and reduces polling on hidden tabs and inactive views. It also does less rendering behind an open conversation and preserves list scroll position when you return.
- **Find a conversation from the CLI.** Run `xmatrix channels --find <words>` to match conversation titles, topics, and summaries in one request. Results include summaries where available.
- **Complimentary Pro for feedback.** Eligible Space owners may receive 30 days of complimentary Pro for feedback that helps improve xMatrix. Space billing shows the grant and its expiry. Feedback invitations include one-click unsubscribe for those emails.

## Updating

- Run `xmatrix update` on each machine to update the CLI and daemon. No manual migration is needed.
- Desktop, Android, and the App Store version for iOS have separate release schedules.
