# xMatrix 4.9.1

This release updates the Desktop app for Windows and macOS and ships the matching CLI and daemon. Desktop users upgrading from 4.0.0 get the following fixes.

## Desktop

- **Windows background service setup can recover from denied Task Scheduler access.** When Windows refuses scheduled task registration, setup uses the current user's sign-in startup entry and starts the daemon directly. Desktop checks the running daemon in this case, so a stale or inaccessible scheduled task cannot incorrectly mark setup as failed.
- **Windows background commands stay hidden.** Where the login task can be edited, it starts the daemon without keeping a terminal window open. Desktop also hides the console windows for background commands it runs.
- **Sign in with the account you choose.** Choosing Google or GitHub opens the provider's sign-in flow so you can choose another account. When you start connecting a provider in Desktop, the browser hands the result back to the app and the connection finishes under the account signed in there.
- **Downloaded updates can install while the computer is idle.** Desktop can restart into a downloaded update when you lock the screen or after five minutes of inactivity. Running Agents continue in the background.
- **Repository details stay visible in deep Windows folders.** Desktop can now show the repository and branch when a long workspace path prevented its Git check from starting. The Windows taskbar icon also has rounded edges.

## Updating

- Update Desktop from the app or download the current Windows or macOS installer from [Download xMatrix](https://xmatrix.sh/download).
- If you installed the CLI separately, run `xmatrix update` on that machine to update the CLI and daemon. No manual migration is needed.
