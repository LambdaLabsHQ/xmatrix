# xMatrix 4.6.4

This update is the website (`xmatrix.sh`) and the CLI/daemon (`4.6.4`, up from
`4.6.1`). Android stays on `4.6.2`, Desktop on `4.0.0`, and iOS on `4.0.4`.
Hub changes listed below are already live.

## Changes

### Agents and workspace (Web)

- **Full-panel desktop Agents matrix.** The Agents matrix now spans the full
  panel with balanced horizontal padding, a unified `Agents` page header and
  single-line status summary, aligned left edges across headings and rows,
  single-line quota bars for scoped windows (such as `Auto · 1mo` and
  `Fable · 1w`), clearer contrast between `Ready`, `Off`, and `+` cells, subtle
  row hover highlights, and sticky-column shadow plus right-edge fade when
  scrolling horizontally.
- **Quieter mobile Agents matrix.** Missing agents render as quiet dots unless
  most of your own machines (at least two) have them installed, multiple agents
  needing attention on one machine are named together without shrinking the
  machine name, and strained CPU/memory/disk readings appear with their bar.
- **Dock trace panel.** Clicking an Agent capsule in the conversation dock now
  morphs the capsule upward into its Trace panel so you can read live activity
  without covering the conversation in a centered modal.
- **Default model dropdown.** Agent settings and Space registration now let you
  pick a default model directly from the harness's reported models, with an
  **Other model…** option for custom names.
- **Icons in Space usage breakdown.** Settings → Billing now displays canonical
  Agent, app connector, and member icons beside each usage row.

### CLI and daemon

- **Antigravity quota reporting.** The daemon and ACP runtime now read Google
  Antigravity (`agy`) model-pool quotas (`Gemini` and `Claude & GPT`) and show
  them alongside scoped trace usage.
- **ACP and Antigravity waiting states.** Long-running tool calls and
  cross-turn Antigravity background tasks now report `waiting` instead of
  appearing idle or stuck busy, preventing premature idle sleep and resuming
  cleanly when background work finishes.
- **Windows startup fallback without Task Scheduler permissions.** When
  `Register-ScheduledTask` is denied on Windows, `xmatrix setup` falls back to
  a per-user logon entry (`HKCU\...\Run`), starts the daemon directly, notes
  the fallback in Machines, and removes both entries cleanly on
  `xmatrix setup uninstall`.
- **Clearer peer discovery in `xmatrix list`.** `xmatrix list` now shows
  `@<name>:<instance>` addresses and channels, groups current-channel Instances
  first, and includes addressable resting peers (`sleeping`, `interrupted`,
  `waking`).

## Fixes

- **Parallel Agent lifecycle controls.** Stopping, reborning, or handing off an
  Agent from the conversation dock no longer disables lifecycle actions on
  other Agents while a request is in flight.
- **Matrix cell confirmation stacking.** Confirmation dialogs opened from a
  matrix cell editor (such as confirming full machine access) now always stack
  above the cell popover.
- **Onboarding device detection.** iOS and Android native wrappers are no
  longer misclassified as the desktop app, and narrow or touch-screen desktop
  browser windows keep desktop setup instructions.
- **Addressable sleeping peers in `@` completion.** The Web `@` menu's **In
  this conversation** section includes sleeping, interrupted, and waking
  Instances while excluding failed or stopped ones.
- **Late control switches (Hub).** Late or expired harness control switch
  results are ignored safely instead of raising server errors.

## Compatibility

- **Web:** updates automatically on reload.
- **CLI / daemon:** run `xmatrix update` to upgrade from `4.6.1` to `4.6.4`.
