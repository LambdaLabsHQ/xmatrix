# xMatrix 4.7.4

This update is the website (`4.7.4`, up from `4.7.2`) and the CLI and daemon
(`4.7.4`, up from `4.7.3`). Android stays on `4.6.2`, Desktop on `4.0.0`, and
iOS on `4.0.4`. Hub changes listed below are already live.

## Website

- **All scoped quota windows are shown and counted.** The website previously
  truncated deduplicated provider quota lists to three entries, dropping a
  fourth window (such as Antigravity's `Gemini · 1w` alongside `Claude & GPT`
  and `Gemini · 5h`) from agent quota chips and limit summaries. Every
  deduplicated quota window now renders and participates in limit verdicts.
- **Loading skeletons match real page layouts.** Startup shells, System
  Overview / Agents matrices on desktop and mobile, Pages lists and documents,
  dynamic tool views, billing plan cards, machine load history charts, and
  admin views now share layout frames with their loaded views—preventing layout
  jumps, blank document flashes, and premature `0 agents working` flashes while
  data loads.
- **Download page channel picker is a borderless paper menu.** Switching
  between Stable and Preview on `/download` now opens a borderless paper menu
  instead of the browser's system dropdown, carrying each channel's description
  inside the menu with Escape, arrow-key, and outside-click support.
- **Phone Agents rows keep their inset when snapping.** Horizontally snapping
  machine rows with more than eight agents on mobile now keep their inline
  padding so the first agent avatar aligns with the machine name instead of
  sitting against the screen edge.
- **Public crawler policy updated.** `robots.txt` on `xmatrix.sh` now allows
  mainstream AI search and training crawlers on public pages while continuing
  to block high-volume scrapers (`Amazonbot`, `Bytespider`, `TikTokSpider`).

## CLI and daemon

- **Quota probe clock-skew tolerance and immediate dead-result cleanup.**
  Protocol and Hub validation now tolerate and clamp up to 5 seconds of forward
  host wall-clock skew on quota probe timestamps instead of rejecting valid
  probes with `machine_command_result_mismatch`. The daemon now drops kept
  `machine_quota_probe_result` files immediately on non-retryable Hub
  rejections or connection-epoch changes, and tightens the fallback cleanup
  window for quota probe results from 1 hour to 5 minutes.

## Compatibility

- **Website:** reload `xmatrix.sh` to get `4.7.4`; nothing to install.
- **CLI and daemon:** run `xmatrix update` on each machine to upgrade from
  `4.7.3` to `4.7.4`.
- No breaking protocol or schema changes. The running Hub already includes the
  quota probe clock-skew handling.

## Known limitations

- Android (`4.6.2`), Desktop (`4.0.0`), and iOS (`4.0.4`) keep their current
  versions.
- The new Manifest V3 Chrome extension (`apps/chrome-extension`) added to the
  repository ships outside the release train and currently loads unpacked only
  until a Chrome Web Store listing and publish workflow exist.
