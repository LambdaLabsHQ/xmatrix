# xMatrix 4.7.4

This update is the website (`4.7.4`, up from `4.7.2`) and the CLI and daemon
(`4.7.4`, up from `4.7.3`). Android stays on `4.6.2`, Desktop on `4.0.0`, and
iOS on `4.0.4`. Hub changes in this batch are already live.

## Website

- **Loading screens match the page they turn into.** Status, Agents, Pages,
  settings, team, apps, admin, billing and Agent traces now show a skeleton laid
  out like the finished view, so rows land in place instead of jumping when the
  data arrives. Opening the app on `/status` or `/pages` shows that destination's
  shell instead of the Channels list, the Status summary no longer flashes
  `0 agents working · No machine online` before it loads, and a page that was not
  prefetched shows its document outline instead of a blank pane.
- **Every quota window shows up.** Agent cards dropped any quota window after the
  third. Antigravity reports four (`Claude & GPT` and `Gemini`, each 5h and 1w),
  so `Gemini · 1w` was missing from the chips and from the usage-limit check for
  Gemini models. All reported windows now appear.
- **The phone Agents row keeps its margin.** On a phone, a machine with more
  than eight Agents scrolls sideways; when it snapped, the first face slid
  against the screen edge. It now stays aligned with the machine name.
- **A quieter channel picker on the download page.** The Stable / Preview choice
  beside the main download is now a small menu in the page's own style, with one
  line on what each channel is and a check on the selected one. It works with
  the keyboard (arrow keys, Escape) and returns focus to the button.
- **AI search and training crawlers may read the public site.** `robots.txt` on
  `xmatrix.sh` now allows mainstream AI crawlers such as `GPTBot`, `ClaudeBot`,
  `Google-Extended` and `PerplexityBot`, so the public guides can be found
  through AI assistants. High-volume scrapers (`Amazonbot`, `Bytespider`,
  `TikTokSpider`) stay blocked.

## CLI and daemon

- **Quota checks are no longer rejected over a few milliseconds of clock
  drift.** A machine whose clock ran slightly ahead of the Hub's could have its
  quota report refused, leaving the check unfinished and a result file kept in
  `daemon-command-results/` for up to an hour. The Hub now accepts readings up
  to 5 seconds ahead (it still rejects anything further in the future), and the
  daemon discards quota results the Hub has refused for good or that belong to
  an earlier connection, keeping any other quota result for at most 5 minutes
  instead of an hour.

## Compatibility

- Run `xmatrix update` on each machine to upgrade the CLI and daemon from
  `4.7.3` to `4.7.4`. No manual migration is needed.
- The running Hub already supports this CLI and website.

## Known limitations

- Windows CLI binaries are not yet Authenticode-signed.
- Android, Desktop, and iOS keep their current versions (`4.6.2`, `4.0.0`, and
  `4.0.4`).
