# xMatrix 3.1.1

Desktop downloads advertised by the stable release APIs now stay on the stable
channel, including the updater metadata files.

## Stable download links match their manifest

The dedicated Desktop release manifest and the combined release manifest
previously linked updater YAML files through an older address that serves dev
releases. The manifest described stable files, but following those links could
return beta metadata with a different version and checksum. Both manifests now
use the explicit stable download address for their Desktop assets.

The native stable updater already used that address. Older dev clients can
also download the beta installers and blockmaps named by their existing feed:
the legacy download route now selects dev for beta filenames and stable for
stable filenames. No updater settings or manual reinstall are needed.

## Compatibility and scope

This is a Web/API patch. CLI/daemon and Desktop stay at 3.1.0, and their release
notes and update links continue to describe those exact downloadable versions.
iOS and Android are unchanged. The settings-card limitations documented in
3.1.0 still apply.
