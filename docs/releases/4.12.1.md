# xMatrix 4.12.1

This patch updates the xMatrix Web app. Refresh the app to get the update. No manual migration or client upgrade is required.

## Web fixes

- Channel readers now see message edits as they happen. Reopening or reloading a conversation also shows the latest text, including edits made while you were away.
- When xMatrix support reads a conversation you shared, the access note and the handoff card now show the latest read count as it changes.

## Hub fixes already live

- After a support handoff expires or you withdraw it, the support agent sees why access ended and learns that only you can share the conversation again.
- The Hub now finishes closing PostgreSQL connections before treating them as released, so database sockets do not keep server processes active after their work ends.
