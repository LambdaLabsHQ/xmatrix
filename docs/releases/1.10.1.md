# xMatrix 1.10.1

Changes since 1.10.0. This Web update fixes a conversation-preview slowdown,
makes connected-app results easier to read, and improves recovery messages.

## Connected-app results

- Long whitespace in a connector receipt can no longer stall a conversation's
  preview. This fixes a regular-expression denial-of-service issue in the
  preview reader.
- Results show the action, its outcome and its returned content. Private reads
  clearly say that only the caller received the result; the command and its
  parameters remain visible as before.
- Conversation previews show the first action and outcome. Long results fold
  above **Show more**, which expands the complete result without covering it.

## Attachment previews and recovery

- Escape closes a Markdown or video preview when its controls have focus. If
  you opened a picture inside Markdown, the first Escape closes the picture
  and a second closes the Markdown preview.
- Failed Agent turns explain provider rate limits, refused access, connection
  problems or an exited program, with steps to continue. Technical details
  remain available under **Details**. A failed turn no longer says the Agent
  could not start when it had already begun.
- The Desktop welcome screen explains common background-service setup
  failures and the steps to recover. These are clearer instructions; this Web
  release does not replace the installed service or installer.

## Pages and shared-service reliability

- Leaving a Page no longer ends co-writing. When you type and a co-writer is
  absent, the Page can wake that Agent. A person's recorded **Stop** remains
  stopped.
- Reconfirming an existing GitHub installation refreshes repository choices.
- Subscribed conversations can receive their CI verdict after a temporary
  GitHub outage instead of losing the notification on the first failed read.
- Platform administrators' Users and Overview reads use narrower indexed
  queries. Counts, permissions and deleted-message filtering are unchanged.

## Compatibility and known limitations

- Reload the stable Web. No CLI/daemon, Desktop, Android or iOS binary is
  promoted by this release; existing native-device and installer limitations
  remain. The shared Hub already serves the Page and delivery changes.
- Older co-writing end markers from the preceding seven days cannot distinguish
  a person's Stop from the former idle timer. Typing can wake those older
  co-writers once; Stops recorded by the updated Hub remain stopped.
- Private results still hide only their returned content. Keep credentials and
  other private values out of invocation parameters.
- A Page call whose confirmation was lost can still require a refresh to
  establish its outcome. Native gestures, device/provider sign-in and full
  multi-Agent recovery retain their separate verification requirements.
