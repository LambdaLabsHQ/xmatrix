# xMatrix 1.7.0

Changes since 1.6.0. This release updates the CLI and machine daemon, bringing
Claude's Ultracode effort to the stable channel. The Web and native shells do
not receive a new build in this release.

## Claude Ultracode

- Choose `ultracode` in Claude's effort controls when using a Claude Code
  version that supports it. xMatrix passes the selection when starting Claude,
  preserves it across respawns and supports changing it during a live session.
- The Agent's effort display continues to show `ultracode` while that mode is
  active, even when Claude records individual turns as `xhigh`. Switching out
  of Ultracode returns the display to the current ordinary effort.

## Conversation reliability

- CLI conversation history and Agent launch context keep ordinary messages
  whole, including repeated messages. Messages are no longer folded as
  obsolete by a later message. Activity entries can still be collapsed.
- On the shared Hub, concurrent uploads of the same attachment converge on a
  verified content reference. Reusing a reference finishes upload bookkeeping
  and repairs interrupted publication instead of leaving an unusable result.
- A resting Agent whose machine is offline now retains its pending wake. Once
  the machine reconnects and becomes ready, it resumes with the latest message
  and catches up on earlier messages through the normal delivery path.

## Compatibility and upgrade

- Run `xmatrix update` to install the stable CLI and machine daemon. Restart or
  reborn existing Agent Instances when they need to use the updated runtime.
  Claude Code must itself support Ultracode; this update does not install or
  upgrade that harness.
- This release publishes CLI/daemon only. The stable Web remains on 1.6.0;
  Desktop and Android native shells remain on 1.2.0. The existing iOS App Review
  submission is unchanged. The shared Hub already runs the reliability fixes.
- No account migration or manual database operation is required. Historical
  supersession annotations remain stored but are ignored by the updated CLI.

## Known limitations

- Updating the daemon does not replace the code in already-running Agent
  processes. Reborn or restart an Instance to pick up the new runtime controls.
- Intermittent database, runtime delivery and credential verification failures
  remain under investigation; the changes above do not establish that all
  underlying causes are fixed.
- This release does not automatically open its notes. Exact-version links in
  updates and downloads remain available.
