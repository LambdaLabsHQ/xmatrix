# xMatrix 4.7.2

This update is the website (`4.7.2`, up from `4.7.0`). The CLI and daemon stay
on `4.7.1`, Android on `4.6.2`, Desktop on `4.0.0`, and iOS on `4.0.4`. Hub
changes in this batch are already live.

## Conversations

- **Scrolling a conversation keeps up with you.** Scrolling quickly through a
  long conversation could show blank timeline before the next messages
  appeared. Most of the delay was the browser restyling far more than the
  messages coming into view: one rule made it restyle every button in the app
  for each message, and the selection and highlight colours were worked out
  again for every element. Both are gone. On a conversation of 300 mixed
  messages at a quarter of normal CPU speed, style work during a scroll fell
  by about half. Mounting the messages themselves is unchanged, so a very fast
  scroll on a slow device can still show a brief gap.
- **Message hover stays steady when you switch conversations.** Opening a
  conversation with the pointer resting over a message no longer flickers the
  row's hover tone and action bar while the list settles behind the first
  screen.
- **A start that its machine never answered says so.** When a connected machine
  takes a start and never runs it, the summon now reports the failure and names
  the machine, and an `@auto` summon goes to the next Agent, after three
  unanswered deliveries instead of ending silently after ten.

## Usage

- **Small usage shows its real value.** A usage meter below 10% rounded the
  value to a whole percent and then printed a decimal it did not have: 4.65%
  read `5.0%` and 0.4% read `0.0%`. It now shows the value itself.

## Download page

- **One download, then every platform.** The page opens on the app icon and a
  single button for the build this device needs; macOS, Windows, Android and
  Web follow as one list, each with its release notes.
- **Stable or Preview, one at a time.** A switch above the main download
  decides the whole page: the main button, every platform row and its release
  notes are the selected channel. Preview adds the Android preview build and
  the beta website. `/download?channel=preview` opens on Preview.

## Compatibility

- Nothing to install: reload the website to get `4.7.2`.
- No protocol change. The Hub that serves this website is already running.
- Text selection and in-page highlights look the same in every browser.
  Browsers that pass highlight colours down from a parent element (Chrome,
  Edge, the Desktop app) take the faster path; Safari and Firefox keep the
  previous one.

## Known limitations

- A usage value from 9.95% up to 10% is shown as `10.0%`.
- The CLI and daemon, Android, Desktop and iOS keep their current versions
  (`4.7.1`, `4.6.2`, `4.0.0` and `4.0.4`). CLI and daemon changes made since
  `4.7.1` reach machines with the next CLI stable.
