# xMatrix 4.7.5

This update is the website (`4.7.5`, up from `4.7.4`). The CLI and daemon stay
on `4.7.4`, Android on `4.6.2`, Desktop on `4.0.0`, and iOS on `4.0.4`. Hub
changes in this batch are already live.

## Website

- **A new deploy no longer interrupts you with an "Update ready" card.** When a
  new version of the website replaces the files an open tab was using, the
  page now reloads itself once, quietly, instead of stopping on a card that
  asks you to reload. Only a second failure in a row shows the manual Reload
  card, so a broken deploy cannot reload in a loop.
- **Unsent messages survive a reload.** What you typed in a conversation's
  composer, the Agents you picked with `@`, and the chosen workspace are kept
  for that browser tab and come back after a reload. They are kept per account
  and cleared when you sign out or switch accounts.
- **Opening a conversation no longer jumps.** On a slow machine, scrolling
  while a conversation was still opening could make the message you were
  reading jump away once the full list took over from the first screen. The
  list now takes over exactly where the first screen was drawn.
- **A roomier Agents page.** The Agents matrix has wider side margins and a
  little less padding per row.
- **The privacy policy covers the xMatrix Chrome extension.** Section 11 now
  says what the extension reads, when, where it sends it, and what it keeps on
  your device.

## Compatibility

- No action is needed. Open tabs pick up the new website on their next reload.
- The running Hub already supports this website.

## Known limitations

- The Chrome extension is not yet in the Chrome Web Store; until it is, load it
  unpacked from `apps/chrome-extension`.
- Windows CLI binaries are not yet Authenticode-signed.
- The CLI and daemon, Android, Desktop, and iOS keep their current versions
  (`4.7.4`, `4.6.2`, `4.0.0`, and `4.0.4`).
