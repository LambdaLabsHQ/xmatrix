# xMatrix 4.14.1

This release updates the website (`4.14.1`, from `4.14.0`, serving `xmatrix.page` and `xmatrix.sh`). CLI and daemon (`4.14.0`), Desktop (`4.9.1`), Android (`4.6.2`), and iOS (`4.11.0`) keep their current versions.

## Website

- **Privacy Policy covers the Chrome extension's on-page conversation card.** Section 11 of the Privacy Policy now describes how the extension works on web pages: selecting text can open a conversation card on the page, each browser tab is tied to one conversation, and approvals and other requests are handled in the side panel. A message that has not finished sending is kept locally in the browser until it is delivered, for at most 10 minutes, and a failure notice is kept for at most 24 hours.
- **The app inside the Chrome extension.** The app the extension loads now powers the on-page conversation card. Approval, confirmation, choice, secret, settings and sign-in cards are shown read-only on the page with a **Handle in side panel** button that opens that message in the tab's side panel. A newly opened side panel shows the conversation from an already open extension view instead of waiting for the Hub, and extension views can share one connection to the Hub.
- **No change to the web app's connection.** The web app, Desktop, iPhone, iPad and Android keep their own connection to the Hub; the shared connection is used only inside the Chrome extension.

## Compatibility and updating

- Refresh the web app to pick up `4.14.1`. The live Hub already supports this release.
- The Chrome extension's on-page card needs extension version `1.1.5`, which is being submitted to the Chrome Web Store.

## Known limitations

- CLI and daemon (`4.14.0`), Desktop (`4.9.1`), Android (`4.6.2`), and iOS (`4.11.0`) are unchanged in this release.
