# xMatrix 1.13.0

This Web release makes Apps easier to connect, brings the live Page's reading
style to shared pages, and adds activity analysis for platform administrators.
It also fixes Channel scrolling that could pull you back after loading older
messages.

## Scroll freely through older messages

Scrolling up or down after older history loads now preserves your movement.
A layout update could previously clear an input before the browser had scrolled,
then mistake that movement for a layout shift and pull it back. Reading anchors
now retain pending input and distinguish it from their own position corrections.
The existing quiet-release and maximum-lifetime limits remain in place.

## An App's next step comes first

Each App page starts with its connection status and the action you need:
connect, reconnect, or repair a connection. A working connection leaves room
for the information underneath rather than showing another connect button.

Connected accounts and resources, Channel subscriptions, recent activity and
permissions are easier to find. Settings follow those details, the command
reference is folded away, and Disconnect comes last. The Apps list groups
connections needing attention separately from working and disconnected Apps.
Connection permissions and approval requirements are unchanged.

## Pages read consistently, inside and outside the app

Published pages now use the live editor's typography and paper, with the page's
location, contributors, update time and a section outline. Tables fit their
content, use quieter row separators and allow wide content to scroll. Reminders
show their names directly.

Task lists use clear checked boxes without striking through completed words,
so mentions and versions remain readable. Quotes appear as tinted callouts.
The homepage's updated examples use the same Page renderer to show how shared
work progresses; English, Chinese, phone layouts and reduced motion are supported.
Publishing and access rules are unchanged.

## Activity analysis for platform administrators

Authorized platform administrators can inspect daily, weekly and monthly active
people, signups, activation, retention and message activity, with date-range
filters and a downloadable daily table. Human activity is based on people's own
messages rather than Agent messages, imports or scheduled work. Settled daily
records make longer-range views faster. These views do not grant administrative
access or change who can read a Space.

## Update and verification limits

Reload the Web to receive the changes. Desktop loads the updated stable Web;
no client reinstall or data migration is needed for this Web update.
CLI/daemon and Desktop binaries remain at 1.12.0, Android at 1.2.0 and stable
iOS at 1.11.1. Native iOS gesture fixes in TestFlight are not part of this release.

Existing requirements for dedicated-identity sign-in, first-machine onboarding,
physical-device and isolated multi-party or payment verification remain open.
Historical database transport timeouts are still under investigation.
