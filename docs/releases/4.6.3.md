# xMatrix 4.6.3

This update is the website (`xmatrix.sh`), bringing the unified **Agents**
matrix to desktop and mobile. CLI/daemon stay on 4.6.1, Android on 4.6.2,
Desktop on 4.0.0, and iOS on 4.0.4. Hub changes listed below are already live.

## Changes

### Agents (Web)

- **One Agents destination.** Status, Machines and Agents are combined into a
  single **Agents** tab so every machine and agent is read and edited in one
  place rather than across three separate views.
- **Editable desktop matrix.** On a desktop, rows are machines and columns are
  agents (`Ready`, working count, `Sign in`, `1w limit`, `Update`, `Off`, `+`
  to install, `—` when unsupported). Choosing any cell opens an anchored editor
  in place to install, sign in, toggle on/off, check usage, or jump to active
  conversations without leaving the table. The trailing `+` adds a new agent
  column and **Add a machine** connects another computer in place.
- **Two-layer mobile avatar matrix.** On a phone, each machine heading (with
  its OS icon and inline exceptions such as sign-in, quota limit, or strained
  CPU/disk) sits above a full-width strip of vertically aligned agent avatars
  with no working-count clutter. Active avatars pulse quietly, attention items
  highlight with an amber ring and semantic badge, strained quota bars appear
  under the avatar, tapping any cell opens an unblurred bottom-sheet editor,
  and a ghost **Add a machine** row guides connecting another computer.
- **Direct agent Space settings.** An agent's page now displays its Space
  working mode and settings directly without an extra modal step.

### Fixes

- Hidden `@auto` in the composer when no Agent in the Space can take work.
- Excluded signed-out, uninstalled, and billing-refused harnesses from unnamed
  `@auto` routing.

## Compatibility

No action is needed. Existing `/status`, `/agents`, `/machines`, and `/local`
links continue to work. The website updates automatically on reload.
