# xMatrix 4.12.0

This release updates the website (`4.12.0`, from `4.11.0`, serving `xmatrix.page` and `xmatrix.sh`) and CLI and daemon (`4.12.0`, from `4.11.0`). Desktop (`4.9.1`), Android (`4.6.2`), and iOS (`4.11.0`, submitted to Apple App Review) keep their current versions. Hub and automation improvements below are already live.

## Website

- **Redesigned `xmatrix.page` homepage across all six locales.** The homepage now renders live xMatrix product components fed a sample Space: a multi-agent live Page beside an iPhone conversation, a Mac conversation window, the full Machines × Agents matrix across every supported harness, and a borderless sticky scroll-driven six-topic comparison pairing live xMatrix interfaces with everyday terminals and windows. Primary actions detect each device to offer the native App download directly alongside App Store and Google Play badges, stages mount lazily as they near the viewport with fixed heights to prevent layout shift, share cards reflect the current `xmatrix.page` title and address, and public site pages no longer make unauthenticated session requests to the Hub.
- **Opt-in diagnostics and quota-probe privacy controls.** Client error diagnostics and quota probes are opt-in with plain-language privacy disclosures, per-machine grant controls, and an in-flow beta notice. Revoking a sign-in quota grant drops every stored reading immediately and updates the Stop/Allow card at once.
- **Hand to xMatrix support.** Added the support handoff dialog, entry points, and privacy documentation so users can grant bounded troubleshooting access explicitly when needed.
- **Conversation, handoff, and mobile polish.** Completed handoff cards preserve the exact successor model and conditions the author wrote, margin comments stay clear of open discussions, messages keep their originating browser-page badge while sending, conversation details link back to the originating page for its author, conversations under the mobile Channel details sheet stop background painting, and composer focus resigns cleanly before modal attachment pickers open.

## CLI and daemon

- **Per-machine quota grants and safer quota probes.** Quota probes now read Codex via `app-server account/rateLimits/read`, query Claude Code and OpenCode directly, and gate OpenCode and Cursor sign-in reads behind explicit per-machine owner grants while keeping local login-file contents off the Hub.
- **Follow GitHub workflow runs without polling.** `xmatrix channel subscribe` now accepts GitHub Actions workflow run URLs in addition to pull requests, delivering run verdicts to the conversation automatically.
- **Mid-turn Antigravity messages and faster history.** Running Antigravity turns join unaddressed human messages mid-turn without interrupting active tools. `xmatrix channel history` supports `--limit` and `--tail`, always prints attachment `ref:` IDs (including cached copies), and parallelizes bounded media downloads. Chrome side-panel `browserPage` context is preserved across Hub turn prompts and CLI history, and support handoffs can include bounded daemon log excerpts.

## Hub and automation (already live)

- **Google Cloud 29-day retention and disconnect purge.** `@gcp` receipts, summaries, and private originals automatically expire after 29 days and delete immediately when Google Cloud is disconnected.
- **Support handoff routes, database performance, and reliability.** Added the support handoff grant model and Hub routes, precomputed Page section changes at write time, fused attachment authority checks into a single read, deduplicated shared Agent registration catalogs, enforced one allowlist for structured diagnostic events, prevented invalid Unicode escapes in PostgreSQL `jsonb` previews, and ensured Agent messages wake only the resting Instances they address.

## Compatibility and updating

- Run `xmatrix update` on each machine to update CLI and daemon from `4.11.0` to `4.12.0`. No manual migration is needed.
- The live Hub already supports this release.

## Known limitations

- Windows CLI binaries are not yet Authenticode-signed.
- Desktop (`4.9.1`), Android (`4.6.2`), and iOS (`4.11.0`, submitted to Apple App Review) are unchanged in this release.
