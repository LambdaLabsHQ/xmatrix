# xMatrix 4.13.0

This release updates the website (`4.13.0`, from `4.12.1`, serving `xmatrix.page` and `xmatrix.sh`) and CLI and daemon (`4.13.0`, from `4.12.0`). Desktop (`4.9.1`), Android (`4.6.2`), and iOS (`4.11.0`) keep their current versions. Hub and connector updates below are already live.

## Website

- **Explicit ZCode harness refusal and updated agent catalog.** xMatrix now explicitly refuses ZCode across the product and documentation. The `xmatrix.page` homepage and agent documentation across all six locales reflect the 34 supported coding agents and document the refusal under `/docs/agents#unsupported-harnesses`.
- **Cleaner first-message launch progress.** When a conversation's first message launches an Agent, the launch line now clearly shows it is working and xMatrix's summon no longer quotes the message back.
- **One-click Google Play reports bucket sync.** Added one-click Google Play `reportsBucket` setup and privacy disclosure in web connector settings (paired with the Chrome extension).
- **Updated privacy and legal documentation.** Clarified xMatrix's non-E2EE trust boundary across the privacy policy, guides, and `SECURITY.md`, and updated Terms and Privacy to state clearly that records kept from connector results belong to the customer.

## CLI and daemon

- **Explicit ZCode refusal.** Removed ZCode session support and added explicit refusal across CLI sign-in, registration, and daemon startup.
- **Runtime and Antigravity responsiveness.** Ensured Antigravity sends its initial acknowledgment on the first step, switched ACP images to load on demand, properly finalized steered executions, and stopped automatically waking failed wrapper starts.

## Hub and connectors (already live)

- **Google Workspace MCP and 29-day retention.** Google Docs, Drive, Sheets, and Calendar connectors now reach Google's Workspace MCP servers. Gmail, Google Docs/Drive/Sheets, and Calendar results expire automatically after 29 days, with one unified retention and customer-record ownership notice that protocol parsers strip cleanly from connector receipts.
- **App Store Connect and Google Play operational analytics.** Added App Store Connect and Google Play operational analytics, auto-saved App Store `vendorNumber` on sign-in, added OAuth support for Play `store_reports`, and fixed Play games-only `slowRendering`, mandatory vitals dimensions, and the 29-day `voided_purchases` window.
- **Vercel connector token hardening.** Switched the Vercel connector to short-lived `client_credentials` installation tokens.

## Compatibility and updating

- Run `xmatrix update` on each machine to update CLI and daemon from `4.12.0` to `4.13.0`. No manual migration is needed.
- Refresh the web app to pick up `4.13.0`. The live Hub already supports this release.

## Known limitations

- Windows CLI binaries are not yet Authenticode-signed.
- Desktop (`4.9.1`), Android (`4.6.2`), and iOS (`4.11.0`) are unchanged in this release.
