# xMatrix 4.0.3

This update adds a public Support page and tells iOS why recording a
video attachment may use the microphone. Refresh the website to get the
page. The CLI and daemon stay on 4.0.1. The Desktop app stays on 4.0.0.
Android is unchanged.

## Support

Open https://xmatrix.sh/support to email hello@xmatrix.sh. You do not
need an xMatrix account. The page links to the user guide and explains
where to manage a subscription bought through Apple. The guide, the site
footer and the App Store listing's support address use this page.

## Video attachments on iPhone and iPad

Choosing to record a video for a conversation or a Page asks for the
camera, and for the microphone so the recording can include sound. The
camera prompt says the camera is for a photo or a video you chose to
attach. xMatrix does not open the camera or microphone until you make
that choice.

## Updating and known limits

Accounts and saved content need no migration. Scripts that start Agents
keep using the explicit launch option from 4.0.0. This release does not
turn on an automatic release-notes popup.

Apple rejected iOS 2.2.0 on 8 November 2026. One finding was a crash
while recording video on an iPad. The other was that the support address
had no direct way to ask for help. This release adds the Support page and
the microphone declaration those findings named. A recording on a physical
iPad has not been confirmed, and Apple's crash report for that rejection
is still being read. This document does not say the crash is fixed, and
it does not say a new build has been submitted to App Review. A TestFlight
build is not App Store acceptance.

A successful send of a large Gmail draft is still not confirmed end to
end. If removing its staged copy fails, a send the provider already
accepted can still show as an error; check the mailbox before sending
again. The Mac full-screen sign-in fix and the Windows daemon-detection
fix still await acceptance on the affected computers.
