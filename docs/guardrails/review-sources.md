- 2026-09-27 Batched production release train: the maintainer asked to batch the release train after two collisions on 2026-09-27. First, a second request claimed the version another request was about to use: two requests for 0.16.465 from the same `main` SHA; the Hub one failed on the existing tag, and the other shipped Web only. Second, GitHub keeps one pending run per concurrency group, so a newer pending train displaced an older one and lost its components. Release requests are now intents. `Production Release Intent` records `refs/release-intents/<run>/<components>` at the dispatching `main` SHA and wakes `Production Release Request`, which is now the train: no inputs, and one repository-wide concurrency group. The train (`scripts/release-train.mjs`):
  - reconciles `refs/release-inflight/<tag>/` intents: a successful Production Release closes them; a train that never tagged, or a failed production run, reopens them; a deploying run leaves them waiting;
  - ships the union of every open intent its frozen SHA contains;
  - chooses the next patch above every release tag, or `main`'s higher `version.json`, and claims it with the existing compare-and-swap before moving the shipped intents in flight;
  - tags and dispatches only once no Production Release is active, so the production group never holds a displaceable pending run.

  `Release Train Next` wakes the train from the default branch when a Production Release completes. Release authority is unchanged: exact frozen SHA, one release commit, selected read-only gates, the scope marker, the immutable annotated tag, production preflight, and the reusable Hub and Web request proofs (the request workflow path is the same). Migration: a train needs an intent, so the old `version_tag`/`release_components` dispatch form no longer exists; in-flight old-form requests finish unchanged because production preflight reads no request inputs. Recovery: `Production Release Recovery` still applies unchanged to a waiting pre-mutation run, and a failed train or production run reopens its intents rather than dropping them.
