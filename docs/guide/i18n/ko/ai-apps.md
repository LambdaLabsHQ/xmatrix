# 외부 AI 앱 연결하기

OAuth 기반 원격 MCP를 지원하는 ChatGPT, Grok, Cursor, Codex 등의 클라이언트에서 xMatrix 페이지와 대화를 바로 사용할 수 있습니다. 서버 URL은 다음과 같습니다.

```text
https://xmatrix-hub.xmatrix.sh/mcp
```

사용 중인 AI 앱에서 이 URL로 커스텀 원격 MCP 서버 또는 커넥터를 추가하세요. 안내에 따라 xMatrix에 로그인하고 앱과 요청 권한을 확인한 뒤 연결을 승인합니다. ChatGPT에서는 이를 커스텀 MCP 플러그인, Grok에서는 커스텀 커넥터라고 부릅니다. 정확한 설정 메뉴는 클라이언트와 요금제에 따라 다릅니다. 공식 MCP Registry에는 `io.github.LambdaLabsHQ/xmatrix`로 등록되어 있습니다.

연결된 앱은 xMatrix에서 본인이 가진 것과 동일한 접근 권한을 받습니다. 읽기 권한으로 스페이스 검색, 페이지 검색·열람, 대화 읽기가 가능합니다. 쓰기 권한까지 허용하면 본인의 이름으로 페이지를 생성·편집하고 메시지를 보낼 수 있으며, 메시지에 에이전트를 멘션해 작업을 지시할 수도 있습니다. 페이지 이력과 메시지 헤더에는 본인의 작성자 표시 옆에 외부 앱이 등록한 이름이 함께 표기되며, 이 이름은 해당 앱이 제공합니다.

"내 로드맵을 찾아서 결정 사항을 요약해 줘" 또는 "내 프로젝트 위키 보여 줘"처럼 물어보세요. MCP Apps를 지원하는 클라이언트는 현재 리비전, 본문 미리보기, xMatrix 원본 열기 버튼이 담긴 페이지 카드를 표시하며, 그 외 클라이언트에는 동일한 페이지 데이터와 원본 링크가 텍스트로 전달됩니다.

연결을 해제하려면 xMatrix 프로필에서 **AI apps**를 열고 해당 앱을 제거하세요. 제거 이후에는 앱이 액세스 토큰을 갱신할 수 없으며, 마지막으로 발급된 액세스 토큰은 최대 15분까지 유효할 수 있습니다. 이미 외부 프로바이더로 전송된 데이터에는 해당 프로바이더의 약관과 개인정보 설정이 적용됩니다.
