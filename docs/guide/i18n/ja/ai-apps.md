# 外部 AI アプリを接続する

OAuth 対応のリモート MCP クライアントであれば、ChatGPT、Grok、Cursor、Codex などから xMatrix のページや会話を利用できます。サーバー URL は次のとおりです。

```text
https://xmatrix-hub.xmatrix.sh/mcp
```

お使いの AI アプリで、この URL を指定してカスタムリモート MCP サーバー（またはカスタムコネクタ）を追加してください。プロンプトが表示されたら xMatrix にサインインし、アプリ名と要求される権限を確認して接続を承認します。ChatGPT ではカスタム MCP プラグイン、Grok ではカスタムコネクタと呼ばれます。具体的な設定画面はクライアントやプランによって異なります。公式 MCP レジストリでは `io.github.LambdaLabsHQ/xmatrix` として登録されています。

接続したアプリには、xMatrix 上のあなた自身と同じアクセス権が付与されます。読み取り権限では Space の一覧取得、ページの検索・閲覧、会話の閲覧ができます。書き込み権限も許可すると、あなたの名義でページの作成・編集やメッセージ送信も行えます。エージェントをメンションするメッセージを送れば、そのエージェントに作業を依頼することも可能です。ページ履歴やメッセージヘッダーには、あなたの名義の横に外部アプリの登録名が表示されます（この名前はアプリ側から提供されます）。

「自分のロードマップを探して決定事項を要約して」「プロジェクト Wiki を見せて」などと話しかけてみてください。MCP Apps に対応したクライアントでは、現在のリビジョン・本文プレビュー・xMatrix で元ページを開くボタン付きのページカードが表示されます。その他のクライアントには同じページデータとリンクがテキストで返ります。

接続を解除するには、xMatrix のプロフィールを開いて **AI apps** を選び、対象アプリを削除してください。削除後はアクセストークンを更新できなくなります（直前のアクセストークンは最大 15 分間有効な場合があります）。すでに外部プロバイダーへ送信済みのデータは、そのプロバイダーの利用規約およびプライバシー設定に従います。
