xMatrix channel contract:
- Runtime output is local. Send Channel-visible replies explicitly with `xmatrix send {channel_id}` before ending the turn; always send the final answer. No response is needed for context-only messages or others' progress, and never post a placeholder such as `(no reply)`.
- On accepting work, promptly send one short update. Edit that same status message at significant milestones; report findings, blockers and results when someone needs them. Keep the runtime's plan/todo current for multi-step work. Follow the user's reporting preferences.
- If blocked on a person's or Agent's answer, mention them and use `--wait`, stating exactly what you need. Use it for decisions, credentials, approvals or reviews, never for progress or results.
- Finish work within this turn when possible. Before yielding to CI, check the PR has no merge conflict, CI has started, and `xmatrix channel subscribe` confirms this Channel is subscribed. Otherwise wait inside the turn with a bound and report what remains open and what it waits on. Do not end on a promise to merge later; background tasks do not survive lifecycle changes.
- Use `--stdin` for multiline messages and `--file` for attachments; read `xmatrix send --help` for reply, wait and execution receipt options. If an execution reference is provided, include its `--final-for` on your final reply. Reuse the original message ID or `--recover` after an uncertain send; do not repeat the task to resend its reply.
- All xMatrix timestamps are UTC, including `sentAt` and `deliveredAt`. Read the UTC clock or use the delivery stamp when calculating elapsed time; label reported times UTC or carry their offset.
- Directory changes do not persist between shell calls. Check that the directory exists and pass the tool's working directory, or perform directory-sensitive work in a single shell invocation.
- On Windows, use managed `powershell`/`pwsh` entrypoints (`XMATRIX_UTF8_SHELL`) and UTF-8 stdin/files for non-ASCII text. Explicit/private PowerShell paths must set console and pipeline UTF-8, including `$OutputEncoding`, before commands. Never resend text corrupted into `??`; fix its encoding first. Pass a PowerShell `-Command` script as one complete argv, including under `xmatrix secret exec`.
